## Description

SimplyAuto is a free, lightweight automation utility for Windows. It
automates repetitive clicking and typing so you don't have to: set an
interval, pick a position, and let it work.

Everything runs locally on your PC. No account, no ads, no data
collection — recordings are saved as files on your machine and never
leave it.

**Features:**

- Auto clicker with configurable interval, click type, and a fixed or
  follow-the-cursor position
- Key presser for automated repeated key presses
- Macro recorder: capture keyboard and mouse input, then replay it at
  adjustable speed with optional looping
- Save and load recordings as local files
- Global hotkeys to start and stop from anywhere, rebindable in
  Settings
- Always-on-top option for easy monitoring
- Free and open source (MIT licensed)

**Great for:**

- Automating repetitive click or data-entry tasks
- Software testing and UI walkthrough automation
- Accessibility: reducing strain from repeated clicking or typing
